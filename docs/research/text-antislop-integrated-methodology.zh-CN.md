# 文字去 AI 味：多维度分析、多范式对照实验与一站式整合架构

更新日期：2026-11-22  
适用对象：`dislop` 核心规则设计者、写作工作流开发者与评估基准维护者。

---

## 核心结论

1. **只盯高频禁用词已经失效**：在 64 份既有样本上拿到 `100%` 检出与 `0%` 误报的 v1 规则，面对 48 份故意避开禁用词的“干净词表 AI 文本”（[text-hard-v2.json](../../benchmarks/datasets/text-hard-v2.json)），检出率直接跌到 **`4.2%`**（`1/24`）。
2. **传统语法检查、论文查重与可读性评分本质上针对的是“前大模型时代”的问题**，不能直接搬来去 AI 味，但各自有一项底层机制值得改造复用：
   - **传统语法检查（LanguageTool / Grammarly）**：专治“写错了”，而大模型生成的恰恰是“语法零失误的均质平庸文本”。可复用其**分区掩码（忽略代码块/引文/URL）+ 行列级 Span 定位 + 分级严重度**。
   - **传统论文查重（Turnitin / k-shingle / Winnowing / SimHash）**：专抓“字面抄袭”，而大模型极少逐字抄袭，而是高频复用**句法骨架与修辞模板**。将其改造为**句首骨架指纹比对（`template-skeleton-echo`）**，即使表面实词全换，依然能定位机械同构段落。
   - **传统可读性工具（Flesch-Kincaid / Hemingway）**：奖励短句、均长与低年级词表，反而会把稿子推向断句口号与平直 AI 腔。将其反转升级为**句长突发性变异系数（Burstiness CV）× 具体锚点密度（Concreteness）双门控**。
3. **单一范式都会顾此失彼，必须做“确定性多维探针 + 离线 5 轴统计画像 + 大模型自愈闭环 + Agent 工作流”的一站式整合**：
   - 仅扩充单词黑名单：难例召回仅 `58.3%`，干净技术文档误报立刻飙到 `12.5%`。
   - 仅用纯统计阈值（如句长 CV）：难例误报高达 `29.2%`，精确率仅 `58.8%`。
   - 仅用传统监督学习（TF-IDF 字符 n-gram / RandomForest 5 折交叉验证）：在分布外迁移（v1 训练 → v2 盲测）时干净误报升至 `20.8%`，且无法给出可执行改稿定位。
   - **多维确定性探针 + 5 轴离线统计画像 + 闭环自愈改写**：112 份检测样本上达 `100.0%` 精确率、`100.0%` 召回、`0.0%` 误报、`100.0%` Node/Python 一致（单篇提取耗时 `0.28 ms`）；喂给云端大模型后，连轻量模型 `gemini-3.5-flash-lite` 在 6 项难例改稿任务上的全通过率也从裸 Prompt 的 **`2/6`（84.0 分）跃升到 `6/6`（100.0 分，+16.0 分）**。

## 1. 六个文字去 AI 味分析角度

| 维度 | 传统单点做法的盲区 | `dislop` 整合后的可观测信号 | 对应实现 |
|---|---|---|---|
| **1. 关键词组合（Co-occurrence）** | 禁单个词（如 `robust`、`助力`）必然误杀真实技术文档 | 不禁单词；仅当同一低事实密度段落内出现 `>= 2` 个不同弱套词（或 `>= 3` 个不限密度）时命中 | `cooccurrence-slop-cluster` |
| **2. 标点与微节奏（Punctuation）** | 只查半角标点或破折号总量 | 覆盖三段对称分号推销句（排除括号多文献引用与冒号参数表）、自问自答设问（`为什么…？因为…` / `The result?`，排除转述提问）、5 逗号连环长句（先剥离 `1,200` 类千分位数字逗号并区分名词清单） | `semicolon-tricolon`、`rhetorical-qa-cadence`、`comma-chain-runon`、`excessive-em-dash-density`、`zh-halfwidth-punctuation` |
| **3. 叙事结构（Narrative Frame）** | 只靠人工通读感觉“像公关稿” | 检出宏大趋势开场（`随着…的不断深入` / `As organizations navigate...`）、展望升华收尾（`展望未来…` / `Looking ahead...`）与连接词团簇（`此外/与此同时/不仅如此` / `Furthermore/Moreover/Additionally`） | `narrative-sandwich-frame`、`literary-narrative-frame`、`zh/en-essay-moralizing-ending` |
| **4. 句法骨架复现（Skeleton Echo）** | 传统查重只看字面 n-gram，实词一换即失效 | 提取段首/句首结构骨架（`在…方面，`、`首先/其次/再次/最后`、`By <verb>ing...`、`First/Second/Third` 及 3 字/2 词同构前缀），跳过键值元数据行 | `template-skeleton-echo` |
| **5. 统计特征与信息密度（Stylometrics）** | 单独看困惑度或句长均匀度会重伤非母语作者与参数文档 | **双门控**：`>= 5` 句且句长变异系数 `CV < 0.24` **同时**具体锚点密度 `< 1.5/百单位` 才标出空洞平直段；全篇持续输出 5 轴画像（CV、相邻句长对比、MATTR、二元重复率、字符香农熵、具体锚点密度） | `low-burstiness-vapor`、`analyzeTextProfile()` / `--profile` |
| **6. 语义层与个人声纹（LLM + Agent）** | 静态规则无法替作者重写隐晦公关腔，也无法贴合个人口吻 | 将前 5 维的精确命中与统计画像喂给 LLM/Agent，锁死原文全部数字与代码标识，改完后自动回跑确定性规则、三阶探针与 5 轴画像，不达标则自动触发手术式修复 | `SKILL.md` + `dislop-cloud`（`review` / `deslop` / `voice_extract`） |

## 2. 传统工具思路的祛魅与改造

| 传统品类 | 本质过时之处 | 值得抽离并现代化的底层机制 |
|---|---|---|
| **传统语法检查器**（LanguageTool / Grammarly） | 假设坏文章 = 拼写错误 + 病句；但大模型产出几乎零语法错误，反而是“过分端庄、滴水不漏”的平均句式 | **分区掩码引擎**（代码/引文/URL 不进正文检查）、行列级 Span 定位、行内抑制注释（`dislop-ignore-next-line`） |
| **传统论文查重**（Turnitin / k-shingle / Winnowing） | 假设抄袭 = 连续字面子串重复；大模型每次生成的字面都不同，重复的是抽象句法模板与论证骨架 | **结构骨架哈希（Syntactic Skeleton Shingling）**：先归一化掉具体名词，再统计跨段落句首骨架碰撞次数 |
| **传统可读性评分**（Flesch / Hemingway） | 机械奖励短句与简单词，会把正常论述压平为等长短句或三字断句口号，反而加重 AI 味 | **反转为“突发性起伏（Burstiness CV）× 具体证据锚点密度（Concreteness）”**：鼓励长短句交错与可核查细节 |

## 3. 六种技术范式的受控对照实验

### 3.1 离线检测对照（95 份纯文本样本，含 48 份难例 `text-hard-v2.json`）

复现命令：`PYTHONPATH=src python3 scripts/run_text_paradigm_experiments.py`（全部 5 折分层交叉验证均零泄漏；单篇特征提取平均 `0.282 ms`）。

| 范式 / 方法 | 全部 95 文本 Precision / Recall / F1 | 全部 95 Clean FPR | 48 份难例 `text-hard-v2` Recall / F1 | 48 份难例 Clean FPR | 关键观察 |
|---|---|---|---|---|---|
| **v1 既有规则基线** | `100.0% / 52.1% / 68.5%` | `0.0%` | `4.2% / 8.0%` | `0.0%` | 避开旧禁用词即近乎失明 |
| **P1a 传统单词黑名单扩充** | `92.7% / 79.2% / 85.4%` | `6.4%` | `58.3% / 68.3%` | `12.5%` | 禁单个常见词直接误杀技术文档 |
| **P1b 纯句长均匀度阈值** | — | — | `41.7% / 48.8%` | `29.2%` | 单独用 Burstiness 误报近三成 |
| **P2 纯统计特征（5 折 LR）** | `71.7% / 68.8% / 70.2%` | `27.7%` | `79.2% / 77.6%`（AUROC `0.865`） | `25.0%` | 有区分力，但误报过高不能当独立门禁 |
| **P3a 传统 NLP：字符 n-gram TF-IDF（5 折 LR）** | `81.4% / 72.9% / 76.9%` | `17.0%` | `95.8% / 90.2%`（AUROC `0.967`） | `16.7%` | 同分布表现不错，但仍误杀六分之一干净稿 |
| **P3b 传统 NLP 分布外迁移（v1 训练 → v2 盲测）** | — | — | `87.5% / 84.0%`（AUROC `0.930`） | **`20.8%`** | 跨文体/话题漂移后误报进一步恶化 |
| **P3c 工程特征 RandomForest（5 折 CV）** | `76.5% / 81.2% / 78.8%` | `25.5%` | `100.0% / 92.3%`（AUROC `0.983`） | `16.7%` | 特征重要性揭示最强信号是**具体锚点密度（0.225）** |
| **P4/P5 升级后多维确定性探针 + 5 轴画像（生产版）** | **`100.0% / 100.0% / 100.0%`** | **`0.0%`** | **`100.0% / 100.0%`** | **`0.0%`** | Node/Python 双端 `100%` 一致，且自查本仓 94 个文件 `0 findings` |

**RandomForest 特征重要性前 7 项（对写作指导最具价值）**：
1. `concreteness`（具体锚点密度：`0.225`）——人类好稿与 AI 空话的最大分水岭；
2. `mattr`（滑动窗口词汇多样性：`0.126`）；
3. `mean_len`（平均句长：`0.123`）；
4. `ttr`（全篇词类比：`0.098`）；
5. `ncr`（zlib 归一化压缩比：`0.089`）；
6. `entropy`（字符香农熵：`0.053`）；
7. `burstiness_cv`（句长突发性变异系数：`0.046`）。

### 3.2 实测大模型对照（6 项难例多段改稿 `revision-hard-v2.json`）

当前生产版 `dislop-bench v2` 采用四维满分 `100` 权重：**D1 多维确定性清除 45 + D2 三阶结构 20 + D3 数字保真 25 + D4 统计节奏与具体度 10**（见 [benchmarks/REPORT.md](../../benchmarks/REPORT.md)）。下表保留 `2026-11-22` 首次在线实测原始日志（当时以 `40/20/25/15` 草案权重计分；无论按草案权重还是最终 `45/20/25/10` 权重，两组 `v2_integrated` 均达到 `100.0 / 100` 且 `6/6` 全通过）：

| 模型 | 模式 | 综合得分 | D1 确定性 | D2 三阶 | D3 数字保真 | D4 统计画像 | 全通过任务 | 提升 |
|---|---|---:|---:|---:|---:|---:|---:|---:|

## 4. 最终落地的一站式立体整合架构

```text
[层 1：零依赖离线确定性多维扫描（0 ms–2 ms，0 联网）]
  ├── 7 套内置包 42 条双语规则（Node `src/core.mjs` + Python `src/dislop/engine.py` 100% 一致）+ 11 条扩展模式库探针（`--patterns`）
  │   ├── 硬残留（寒暄/占位符/裸 Markdown/空链接）
  │   ├── 词法共现（cooccurrence-slop-cluster，不禁单词）
  │   ├── 标点微节奏（三段分号/自问自答/5 逗号连环句/破折号/中文半角）
  │   ├── 宏观叙事与骨架（三明治开收尾/连接词团簇/句首骨架复现）
  │   ├── 垂直场景探针（工程 RFC/复盘、合规极限词/无基线倍数、高管 PPT 标题与连页版式）
  │   └── 统计双门控（低突发性 × 低具体度空话）+ 随包 14.6 KB Pocket ML（`--ml`）
  └── 5 轴离线统计画像（`dislop check --profile` / 本地 MCP / 浏览器工作台实时显示）
      └── Burstiness CV · Concreteness/100u · MATTR/Entropy · Punctuation · Structure Risk

[层 2：Agent 零安装写作规约（`SKILL.md` + 4 张本地 `./references/*.md` 参考卡）]
  └── 先防后查：写作前规避 5 类结构性习惯，写完后调本地 CLI `--profile` 逐项核对

[层 3：可选云端大模型自愈流水线（`dislop-cloud` / Remote MCP）]
  ├── 预检：提取 42 条规则命中 + 5 轴统计画像 + 原文锁定数字清单
  ├── 定向改写：把具体问题和个人写作声纹卡（`dislop_voice_extract`）一并喂给模型
  └── 自动复检与手术修复：复跑规则 + 三阶探针 + 5 轴画像 + 内部数字与限定词保真护栏，不过线自动二次修复
```

这套整合体系既保留了**隐私敏感场景下 100% 离线、零黑盒、零误报**的工程底线，又让**大模型与 Agent 在明确诊断信号和硬门禁约束下发挥语义改写长板**，避免陷入“用规则硬卡误伤好稿”或“把全文扔给裸 Prompt 换来另一种 AI 腔”的两种极端。
