# `dislop` 商业模式、Open-Core 边界与增值服务设计

日期：`2026-11-21` · 状态：战略设计基线（关联 `ROADMAP.zh-CN.md` 与 `server/`）

这份调研回答三个直接影响项目走向的问题：开源和闭源的边界该切在哪里、用 Google Cloud / Gemini 跑托管大模型后台的成本与防刷账怎么算、以及哪些增值服务能让用户持续付费而不是用完一次就走。

---

## 1. 行业对标实测（2025–2026 公开定价与模式）

我们横向核对了 9 个与 `dislop` 形态最接近的真实产品，覆盖开源内核开发工具、写作审校 SaaS 与远程 MCP 变现三类路径。

### 1.1 开源开发工具（Open-Core vs. 纯开源）

| 项目 | 开源协议 | 商业化结构 | 自托管现实与付费转化点 |
|---|---|---|---|
| **Vale** | MIT | 无官方商业云，仅靠社区资助与赞助 | 单文件 Go CLI，开发者口碑极好，但没有托管产品和团队平台，难以形成持续商业收入。 |
| **Langfuse** | MIT | 阶梯订阅（Hobby \$0 / Core \$29 / Pro \$199 / Enterprise \$2,499/月）+ 超量线性计费（\$8 / 100k units） | 核心全开源，但自托管需维护 ClickHouse/Postgres/Redis/S3；云端卖免运维、长周期留存、RBAC 与合规审计。 |
| **PostHog** | MIT | 纯按量阶梯计费 + 慷慨免费月额度，不收按人头底费，用户可设硬支出上限 | 核心全开源，但官方明确不对自托管提供商业排障与独立安全补丁；规模上来后企业普遍转托管云。 |

### 1.2 写作与去 AI 味 SaaS（与 `dislop` 网页端最直接可比）

| 项目 | 免费版 | 付费定价 | 留存与付费驱动 |
|---|---|---|---|
| **Hemingway Editor Plus** | 网页端规则高亮永久免费（免登录，靠搜索流量获客） | 约 \$8.33/月（年付约 \$100/年） | **与 `dislop` 最接近的对照**：免费规则检查建立信任，付费一键云端 AI 改写（按清晰度规则改写）负责转化。 |
| **Grammarly** | 基础语法检查 + 100 次/月 AI 提示 | Pro 约 \$12/月（年付 \$144）或 \$30/月（月付），含 2,000 次/月 AI | 个人端靠全场景嵌入，高留存来自团队/企业版的品牌语调（Brand Tone）与统一写作规范。 |
| **QuillBot** | 限 125 词改写 / 1,200 词摘要 | 年付 \$8.33/月，月付 \$19.95/月 | 靠字数硬门槛转化，但纯同义词改写缺少工作流绑定，用户流失率高于团队规范类产品。 |

### 1.3 远程 MCP 商业化标准（2025–2026）

MCP 协议本身不含计费原语，成熟服务全部采用 **开源客户端/协议层 + 托管网关 Bearer/OAuth 计量**：

| 项目 | 免费额度 | 付费模式 | 关键设计 |
|---|---|---|---|
| **Firecrawl MCP** | 1,000 credits/月（免绑卡） | 订阅额度池（Hobby \$16–\$19/月 5k credits；Standard \$83–\$99/月 100k credits） | 按工具计算权重扣点：轻量抓取消耗 1 credit，结构化深抽取消耗更高权重。 |
| **Exa MCP** | \$10/月免费额度 | 按量计费（\$4–\$15 / 1,000 次搜索，按深浅分档） | 零月租门槛，适合自动化 Agent 与工作流按需消费。 |
| **Context7 MCP** | 1,000 次/月（仅公开仓） | \$10/席位/月（含 2k–5k 次 + 私有仓解析，超量约 \$5/1k 次） | 免费开放公开知识，付费切在**私有数据与团队席位**。 |

## 2. 核心判断：为什么采用 Open-Core，而不是把薄 MCP 后台闭源

如果只把调用 Gemini 的薄代理（约 300 行 HTTP/MCP 路由）闭源，会同时遇到三个问题：

1. **没有技术壁垒**：薄代理 10 分钟就能重写，闭源挡不住竞争对手。
2. **开发者不买“二次套壳订阅”**：Claude Code、Cursor、Codex 用户手里已经有顶级模型订阅，装上开源 `SKILL.md` + 本地 CLI 就能直接用自己的模型跑闭环，不会再花 \$10–\$20/月让你代调一次通用模型。
3. **损害开源信任与企业准入**：`dislop` 的初始心智是离线、可审计、不乱改事实。基础单机后台保持开源（BYOK 自带 Key）反而能让安全团队放行，并把“懒得自建运维、要重能力、要团队协同”的用户自然导流到托管云。

因此，边界应当切在**单机能力开源、云端多租户与重能力商业化**（Open-Core）：

| 层级 | 仓库与许可 | 包含内容 | 战略目标 |
|---|---|---|---|
| **开源层（Community / BYOK）** | `dislop-ai/dislop`（Apache-2.0） | 双端零依赖确定性引擎、`CLI`、`SKILL.md`、`Plugin`、本地 `stdio MCP`、浏览器离线工作台、`Awesome Anti-Slop`、`dislop-bench`、单机 BYOK `server/` | 拿 GitHub Star、建立行业规则与评测标准、零摩擦扩散、赢得企业安全审查。 |
| **商业云端层（Hosted Cloud）** | 私有仓库 `dislop-cloud` | 账号与 OAuth、API Key 签发、额度计量与防刷网关、支付订阅、官方托管 `dislop.com` 在线大模型体验与 `mcp.dislop.com`、`.docx`/`.pptx` 原排版深度改稿、网页/PPT 渲染截图 + VLM 设计审校、个人/团队品牌声纹库（`dislop.voice`）、GitHub App 自动巡检 | 靠**免配置省事 + 难自建的多模态重能力 + 团队治理 + 合规 SLA** 收费。 |

## 3. Google Cloud / Gemini 成本账与隐私红线

### 3.1 隐私红线：绝不用免费层跑公网用户稿件

公开条款显示，Google AI Studio 免费层的请求内容可能被用于模型改进；而 **Google Cloud Vertex AI 付费层**与 **AI Studio 付费层**明确不将客户数据用于训练。`dislop` 面向的是未发布的技术方案、汇报材料和商业文档，官方托管后台必须运行在**不用于训练数据的付费端点**，并做到服务端零稿件落盘日志。

### 3.2 单次成本与毛利测算（基于 2025–2026 公开单价）

以一份 1,500 字中文/英文稿件（约 2,500 输入 tokens + 1,500 输出 tokens）为基准：

| 调用类型 | 推荐模型档位 | 参考公开单价（每百万 tokens） | 单次成本估算 | 建议消耗权重 |
|---|---|---|---|---|
| `dislop_check` | 确定性引擎（无 LLM） | \$0 | **\$0.0000** | `0 credits` |
| `dislop_review`（三阶审校） | Flash-Lite 档（轻量快速） | 输入 \$0.10 / 输出 \$0.40（缓存读 \$0.01） | **约 \$0.00085** | `1 credit` |
| `dislop_deslop`（去味改写 + 确定性复检） | Flash 档（高质量改写） | 输入 \$0.30 / 输出 \$2.50（缓存读 \$0.03） | **约 \$0.0045** | `2 credits` |
| `dislop_visual_audit`（规划中：页面/PPT 渲染 + VLM） | 视觉 Flash 档 + 无头渲染 | 含截图渲染与多模态 tokens | **约 \$0.008–\$0.015** | `5 credits` |

**毛利与免费获客预算**：
- 即使官方提供每月 **10,000 次免费体验**（按 70% `review` + 30% `deslop` 混合），月模型成本仅约 **\$19.5**，是非常便宜的获客预算。
- 对标 \$12/月 Pro 订阅（含 1,000 credits，约可跑 500 次深度改写或 1,000 次审校），即使重度用户用满全部额度，模型成本仅约 **\$0.85–\$2.25**，**毛利率保持在 80% 以上**。

### 3.3 公网防刷五道硬护栏

| 防护层 | 具体配置 | 防什么 |
|---|---|---|
| 独立项目与独立 Key | 单独建 Google Cloud 项目与专用 API Key | 与个人或其他业务完全隔离，出问题一键吊销。 |
| 硬性配额上限（Hard Quota） | 控制台设 RPM 与日额度硬顶 + 服务端 `DISLOP_DAILY_LLM_LIMIT` | 防止分布式脚本撸穿账单（邮件告警拦不住实时扣费）。 |
| 匿名极小额度 | 离线检查不限次；主动点 AI 深度去味限每 IP 每日 3–5 次、单次 ≤ 4,000 字 | 让真实访客能试到效果，同时压低无成本刷接口收益。 |
| 登录解锁月度额度 | GitHub / Google 登录后给 30 credits/月 | 抬高批量薅羊毛成本，同时沉淀高意向用户。 |
| 体积、超时与脱敏 | 单请求 ≤ 64 KB、上游超时 ≤ 30 秒、错误经 `redactSecrets()` 脱敏 | 防止大包打爆内存或上游报错意外回显密钥。 |

## 4. 产品分层与定价方案（混合订阅 + 额度包）

参考 Hemingway Plus、Firecrawl 与 Context7 的组合，覆盖个人创作者、Agent 开发者与团队三类买单人群：

| 档位 | 目标人群 | 价格建议 | 包含能力 |
|---|---|---|---|
| **Free（开源 + 轻量体验）** | 所有人、开源社区、开发者 | \$0 | 全部离线工具（CLI、Skill、Plugin、本地 stdio MCP、浏览器工作台、BYOK 自托管 `server/`）；官网匿名每日 3–5 次 AI 体验；登录后 30 credits/月（含官方远程 MCP 试跑）。 |
| **Pro（个人与创作者）** | 写作者、产品经理、独立开发者 | **\$9–\$12/月**（年付）或 **\$15/月**（月付） | 1,000 credits/月（覆盖 `review`/`deslop`/官方远程 MCP）；`.docx`/`.pptx` 原排版导出（规划）；3 套个人声纹（`dislop.voice`）；无训练数据承诺。 |
| **Credits（按量包）** | 低频用户、n8n/CI 自动化、Agent 玩家 | **\$10 买 1,000 credits**（12 个月有效，无月租） | 消除“怕订阅浪费”的心理阻力，直接适配远程 HTTP MCP 与 API 调用。 |
| **Team（团队与企业）** | 内容/市场团队、技术文档组、咨询与研发团队 | **\$29/席位/月**（或 \$99/月含 5 席位） | 共享品牌语调与团队规则库、GitHub App PR 自动巡检、网页/PPT 视觉 VLM 审查、团队用量看板、私有化部署支持与合规 SLA。 |

## 5. 真正拉开差距的四大付费增值服务（脱离薄套壳）

开源层已经把规则检测、Skill 提示和基础 BYOK 做透，云端付费层只押注**本地很难配好、或需要持续沉淀状态**的四项能力：

| 增值能力 | 解决什么痛点 | 为什么用户愿意付费而不自己搭 |
|---|---|---|
| 原排版文档一键洗稿（`.docx` / `.pptx` Round-Trip） | 拖入 Word 或 PPT，逐段去 AI 味并复核数字保真后保留原样式、母版、图表和目录重新导出 | 非技术用户付费意愿最强的痛点，不需要碰 CLI 或 API Key。 |
| 网页与 PPT 视觉多模态审查（Visual Anti-Slop） | 后台无头渲染 HTML / `.pptx` 为真实截图，再用 VLM 审校版式拥挤、模板审美和连续同版式 | 需要重渲染环境与多模态调度，个人几乎不会本地维护。 |
| 个人与团队声纹库（`dislop.voice` 云端托管） | 导入 5–10 篇作者或公司历史好文，提炼句长节奏、用词偏好与禁词边界 | 让改稿保留“自己/品牌的声音”，且随团队使用越用越粘。 |
| 经 `dislop-bench` 验证的多步专项流水线 | 确定性检查 → 分文体改写 → 自动复检二/三阶套话 → 数字与链接零漂移核对（失败重试） | 用公开 Benchmark 分数证明比裸调通用模型更稳，直接省掉调 Prompt 成本。 |

## 6. 分阶段验证路线（先测需求，再做重计费）

| 阶段 | 时间与投入 | 动作 | 核心验收指标（决定是否进入下一阶段） |
|---|---|---|---|
| **阶段 0：低成本需求验证** | 1–2 天，模型预算 < \$20/月 | 在官方服务器部署 `server/` + 独立 Vertex AI / Gemini 付费 Key（硬日上限），官网工作台增加可选「AI 深度去味（免费试 3 次）」与官方远程 MCP 试跑；额度用完引导「免费自托管 BYOK」或「留邮箱预约 Pro」。 | 连续 2–4 周观察：匿名点击率、触达日限额人数、留邮箱/预约 Pro 转化率、以及 Web 端 vs 远程 MCP 哪边拉动更强。 |
| **阶段 1：轻量收款与按量包** | 1–2 周 | 上线 GitHub/Google 登录 + Stripe 一次性 Credits 包（\$10）与 Pro 订阅（\$12/月），开通官方托管 `mcp.dislop.com` 与 `.docx`/`.pptx` 原排版导出 MVP。 | 首批真实付费用户数、单用户月均消耗 credits 与毛利率验证（目标 > 75%）。 |
| **阶段 2：重能力与团队版** | 1–2 个月 | 推出云端个人/团队声纹库、网页/PPT 截图 VLM 视觉审校、GitHub App 自动巡检与 Team 席位订阅。 | 团队试用转付费率、次月留存率与 Benchmark 跨模型跑分领先幅度。 |
