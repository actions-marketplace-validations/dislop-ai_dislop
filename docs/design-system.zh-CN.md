# 品牌、视觉与界面设计规范

[English](./design-system.md)

`dislop` 用于检出文稿、演示文稿与前端界面里的模板化水词和结构缺陷，因此项目自身的品牌标识、文档横幅与官方网站（`site/`）采用同一套可静态核验的设计语言：**建筑网格上的印刷校样单（Architectural Galley Proof）**。本文所有约束均由 CI 中的 `dislop check . --fail-on warning` 自动检查。

## 1. 视觉定位：同时避开两代 AI 默认模板

当前生成式开发工具页面普遍落入两类高频视觉套路：

1. **第一代模板（2023–2025）**：深蓝黑底配蓝紫粉霓虹渐变、满屏 `rounded-full` 胶囊标签与渐变裁切大标题。
2. **第二代模板（2025–2026）**：当提示词禁止紫色渐变后，模型普遍退回暖米白底（`#F7F5F0`）、Tailwind 暖黑（`#1C1917`）配朱砂橙红——形成新的同质化“暖色人文模板”。

`dislop` 同时避开这两类默认解，回到校对这一行当本身的器物逻辑：

- **印刷清样（西方 Galley Proof 与国家标准 GB/T 14706《校对符号及其用法》）**：中性棉浆纸白底、高对比碳黑墨迹、待审文稿用衬线体排版，批注置于右侧页边栏并与原文行号对应。
- **工程结构标尺**：使用连续的 `1px` 细实线划分版面分栏，单元格采用 `0–4px` 直角/微圆角，不叠毛玻璃和弥散阴影；首屏直接提供可编辑、可复检的校样工作台，不放空洞宣传画。

## 2. 品牌图形与字标

- **图形标识（`assets/logo.svg`）**：取自中西共通的**删除号（*dele* / GB/T 14706 删除号）**——一笔横线穿过浅色原稿行，向右上方挽出圆环后利落撇出。图形在 `16×16`（浏览器标签页图标）、`64×64`（GitHub 组织头像）与 `512×512` 下均保持环内留白通透、不糊成色块。
- **字标**：全小写无衬线粗体 `dislop`（`letter-spacing: -0.025em`），不挂版本号胶囊、星芒图标或多层套框。
- **仓库双主题横幅（`assets/banner-light.svg`、`assets/banner-dark.svg`）**：在 `README` 中通过 `<picture>` 标签自适应 GitHub 浅色与深色模式，右侧直接展示真实校对与事实锁定样本。

## 3. 色彩令牌与深色模式单调亮度阶梯

全部文字与背景组合均实测通过 **WCAG 2.2 AA 标准（正文 >= `4.5:1`，大字号 >= `3.0:1`）**。深色模式下，表面明度（`L*`）按“外框画布 -> 正文清样纸 -> 悬浮控件”严格单调递增，杜绝底层比上层卡片更亮的 Z 轴倒置（仅代码/输入框内凹槽 `--inset` 允许更暗）。

| 令牌 | 用途 | 浅色值 | 浅色清样对比度 | 深色值 | 深色明度 `L*` / 对比度 |
|---|---|---|---|---|---|
| `--stage` | 页面外围画布 | `#F6F7F5` | — | `#0E1012` | `L* = 4.6` |
| `--sheet` | 主清样栏 / 内容面板 | `#FFFFFF` | — | `#15181C` | `L* = 8.1`（高于 `--stage`） |
| `--raised` | 激活态控件 / 顶栏悬停 | `#ECEEE9` | — | `#1D2127` | `L* = 12.6`（高于 `--sheet`） |
| `--inset` | 代码块与原始输入凹槽 | `#F1F3F0` | — | `#0A0C0E` | `L* = 3.1`（内凹） |
| `--rule` | `1px` 结构分界线 | `#D5D7D2` | 结构细线 | `#2A2F37` | 结构细线 |

## 4. 红蓝双铅笔与保留号（Stet）校对语义

任何状态均不只靠颜色区分，而是同时绑定**线型**与**等宽字母标签**：

1. **朱红实线（`--mark-error` + `2px solid` 下划线 + `error`）**：代表 `core` 客观交付错误（本机路径泄露、未填占位符、AI 寒暄壳、对比度不达标、幻灯片越界）。页面任何纯装饰元素严禁使用红色。
2. **群青虚线（`--mark-warn` + `1.5px dashed` 下划线 + `warn` / `info`）**：代表文体审美包提示（铺垫套话、`不是 A，而是 B` 对比口号、三连短句或幻灯片文字墙）。
3. **墨绿点划线（`--mark-stet` + `1.5px dashed` 下划线 + `stet`）**：代表 `dislop verify` 锁定的受保护事实（数值、单位、“最多/至少”限定词、链接、代码片段与引用编号），即校对标准中的**保留号（stet）**。

## 5. 字体栈与中英混排细节

全站零外部字体 CDN 请求（不连 `fonts.googleapis.com` 或 `jsdelivr`），兼顾中国大陆与海外首屏直开速度，并确保浏览器工作台零外发连接。

- **待审文稿衬线栈**：`Georgia, "Source Serif 4", "Noto Serif CJK SC", "Songti SC", "STSong", "Microsoft YaHei", serif`（Windows 下以雅黑兜底避免回退点阵中易宋体；单行宽度控制在英文约 `65ch`、中文约 `36` 字；行高英文 `1.6`、中文 `1.8`）。
- **界面控件与标题无衬线栈**：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。
- **行号、规则 ID 与命令行等宽栈**：`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`，统一开启 `tabular-nums` 等宽数字对齐。

## 6. 网格、控件与平面纪律

- **1px 通栏标尺**：主体最大宽度 `1200px`，左右以连续 `1px` 纵向标尺收束，模块间以通栏水平细线切分，不堆叠三层套盒（`box-in-box-in-box`）。
- **清样三栏自适应（桌面端三栏，`< 1040px` 批注落至底部，`< 820px` 移动端单栏流式折叠）**：左侧为标本目录，中间为带行号槽的可编辑原稿纸，右侧为删除测试与改稿对照；小屏下保证 `375px` 宽度零横向溢出。
- **零死点击控件**：所有按钮与链接均对应真实交互或有效锚点；圆角统一限制在 `0–4px`；过渡动画不超过 `120ms` 并遵循系统 `prefers-reduced-motion` 设置。
